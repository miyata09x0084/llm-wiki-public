# nextjsjp.org トップページ

[[nextjsjp.org]] のランディングページ。サイト紹介と [[Next.js]] 16 新機能のダイジェスト。

## 要点

- nextjsjp.org は**非公式・有志による** Next.js 日本語ドキュメントサイト(運営: judewei_dev 氏)
- 公式(nextjs.org)と同一の URL 構造 — ドメイン差し替えだけで英↔日切り替え可能
- Next.js 16 の6大新機能を紹介:
  1. [[Turbopack]] がデフォルト有効(コンパイル・HMR 高速化)
  2. [[Cache Components]](実験的 PPR の後継、安定版)
  3. 非同期リクエスト API 完全対応(`cookies` / `headers` / `searchParams`)
  4. ルーティングのプリフェッチとキャッシュ改善
  5. React 19.2 / React Compiler 対応
  6. middleware → proxy へ移行
