# BERT (2018)

**双方向 [[Transformer]] encoder を MLM(masked language model、文中の15%を隠して当てる学習)で事前学習し、出力層1枚の fine-tuning(下流タスクでの全パラメータ追加学習)で11タスク全て SOTA を取った論文。[[事前学習とfine-tuning]] パラダイムの確立者。** Devlin ら4名(Google AI Language)、NAACL 2019。arXiv:1810.04805(本要約は v2、2019-05 改訂版。取り込み時の強調指示: 機構の理解重視)。

## 中核機構 — 「自分が見えてしまう」問題を15%のマスクで回避した

通常の言語モデルが単方向(左→右)なのは、双方向にすると多層の文脈を経由して各単語が間接的に自分自身を参照し、予測が自明になるため。MLM はマスクでこの循環を断ち、深い双方向学習を初めて可能にした。

- **手順**: 入力トークンの15%をランダムに選び、元のトークンを当てさせる(1953年の Cloze 穴埋めテスト由来)
- **80/10/10 の工夫**: 選んだ15%のうち 80% は [MASK] トークンに置換、10% はランダムな別単語に、10% はそのまま残す。なぜなら [MASK] は fine-tuning 時に一切現れず、事前学習とのギャップになるため。どれが置換済みか分からない状態を作り、全トークンの文脈表現を維持させる
- **双方向性の効果測定**: ablation(部品を外して寄与を測る実験)で左→右のみ(=GPT-1 方式)にすると SQuAD(質問応答ベンチマーク)F1 88.5→77.8 と大幅劣化。マスク比率の変更には頑健(Table 8)— 効いているのはマスク戦略の細部でなく双方向性そのもの
- **副目的 NSP**(next sentence prediction、2文が連続かを当てる): 文間関係の学習用。ただし後日談に⚠️あり(後述)

## 入力表現 — [CLS] と [SEP] であらゆるタスクを「1系列」に詰める

タスクごとにモデル構造を変えない工夫が入力側にある。単文も文ペア(質問+文書)も同じ形式に潰す。

| 部品 | 役割 |
|------|------|
| [CLS](先頭の特殊トークン) | 最終層のこの位置のベクトルが系列全体の代表 — 分類タスクの出力口 |
| [SEP] + segment embedding | 文 A / 文 B の区切りと所属表示 |
| WordPiece(単語をサブワードに分割する方式、語彙3万) | 未知語をなくす |
| 入力ベクトル = token + segment + position の3埋め込みの和 | 位置情報は学習型(原型 Transformer の正弦波から変更) |

## fine-tuning — 新規パラメータは出力層1枚、コストは事前学習の1/100以下

事前学習済みの全パラメータを初期値に、タスクごとに数エポックだけ追加学習する。構造の付け足しが最小である点が feature-based 方式(ELMo)との違い。

- 分類: [CLS] のベクトル C に分類行列 W を掛けて softmax(合計1の確率分布に変換する関数)。新規学習対象は W のみ
- スパン抽出(SQuAD): start / end の2ベクトルと各トークンの内積で答えの開始・終了位置を選ぶ
- コスト実測: 事前学習は BASE で 4 Cloud TPU(Google の学習専用チップ)×4日。fine-tuning は TPU 1台で1時間以内 — 高価な学習は1回、安価な適応は何度でも、の分業が成立

## 結果 — 11タスク SOTA、340M は 110M に全勝

- GLUE(言語理解ベンチマーク集)80.5 で +7.7pt、MultiNLI 86.7、SQuAD v1.1 F1 93.2、SQuAD v2.0 F1 83.1
- **対照実験としての設計**: BERT_BASE(110M パラメータ)は GPT-1 と意図的に同サイズ。アーキテクチャ差はほぼ attention のマスク方向のみ — 勝因を双方向性に絞り込む設計
- **サイズ効果の早期実証**: LARGE(340M)が BASE を全タスクで上回る。学習データ 3,600件の MRPC でも効く — [[スケーリング則]](リスト#4)の前触れ
- 事前学習データ: BooksCorpus 8億語 + English Wikipedia 25億語 = 33億語

## ⚠️ 矛盾・後日談 — NSP の寄与は論争あり

本論文は NSP 除去で QNLI・MNLI が劣化すると報告(Table 5)。ただし RoBERTa(2019、モデル知識・未 ingest)は NSP を外しても劣化しないと報告しており、寄与は確立していない。RoBERTa を ingest したら更新する。

## LLMへの系譜 — encoder 家系の代表、ただしパラダイムは GPT-3 が覆す

- encoder 家系([[Transformer]] の3家系参照)の代表として、分類・検索・埋め込みで長く主流に
- ただし MLM は穴埋め専用で生成ができない。したがって生成 AI の主役は decoder-only(GPT 系)へ
- 確立した「事前学習→fine-tuning」も、リスト#3 GPT-3 の「fine-tune 不要(in-context learning)」に覆される — 詳細は [[事前学習とfine-tuning]]
