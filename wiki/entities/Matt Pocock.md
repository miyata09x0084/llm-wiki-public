# Matt Pocock

TypeScript 教育の第一人者から AI エージェント活用の発信者に軸足を広げた英国のデベロッパー教育者。「vibe coding ではなく real engineering」を旗印に、古典的エンジニアリング原則をエージェント運用に翻訳する立場を取る。

## 活動: TypeScript 教育から AI Hero へ

- **Total TypeScript** — TypeScript 学習教材の定番シリーズの作者として知名度を確立
- **AI Hero**(aihero.dev) — AI 活用エンジニアリングの教育・ニュースレター。読者約6万人([[Skills For Real Engineers (mattpocock skills)]] README 記載)
- **mattpocock/skills** — 日常業務で使うエージェントスキル集を公開。skills.sh と Claude Code plugin の2系統で配布

## 思想: プロセス所有型フレームワークへの対抗

GSD・BMAD・Spec-Kit のような「プロセスがユーザーを所有する」アプローチを批判し、小さく・改造可能・合成可能なスキルを提唱する。よりどころは The Pragmatic Programmer、DDD(Eric Evans)、A Philosophy of Software Design(John Ousterhout)などの古典で、「AI 時代こそ基礎が効く」という立場が一貫している。

詳細は [[Skills For Real Engineers (mattpocock skills)]] を参照。
