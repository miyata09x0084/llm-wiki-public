# Attention Is All You Need (2017)

**RNN/CNN を捨て attention のみで系列変換を行う [[Transformer]] を提案した論文。本質的貢献は逐次計算の除去=並列学習の解放で、これが後の[[スケーリング則]]と GPT 系譜の前提条件になった。** Vaswani ら8名(Google Brain / Google Research)、NIPS 2017。arXiv:1706.03762(本要約は v7、2023-08 改訂版。強調指示: 機構の理解重視 — 2026-07-16 に系譜重視から改訂)。

## 全体構成 — 2種のサブレイヤーを「残差+正規化」で包んで積むだけ

encoder(入力全体を表現に変換する側)は [self-attention → FFN] を6層、decoder(出力を1トークンずつ生成する側)は [masked self-attention → encoder-decoder attention → FFN] を6層。全サブレイヤーを LayerNorm(x + Sublayer(x))(残差バイパス+層単位の正規化)で包む。

- 全層の次元を d_model=512 に統一 — 残差接続で足し算するための制約
- **FFN**(feed-forward network): `FFN(x) = max(0, xW₁+b₁)W₂+b₂`。各位置に独立・同一適用される2層全結合(内部 2048)。attention が文脈を「混ぜ」、FFN が「変換する」分業
- **埋め込みの重み共有**: 入力・出力の埋め込み行列と softmax 直前の線形層で同一の重みを使い、√d_model 倍する
- **positional encoding**: 波長 2π〜10000·2π の等比数列をなす正弦波。採用理由は、任意の固定オフセット k に対し PE(pos+k) が PE(pos) の線形関数になり相対位置を学びやすいという仮説。学習型埋め込みと性能ほぼ同一(Table 3 行E)で、学習時より長い系列への外挿可能性から正弦波を選択

## 核心の数式 — dot-product 攻めは「行列積で書ける」から勝った

attention の選択肢は additive(小さな NN で類似度を計算)と dot-product(内積)の2つで、理論計算量は同等、実速度は GPU の行列積最適化に乗る dot-product が勝つ。

```
Attention(Q,K,V) = softmax(QKᵀ/√dk) V
```

- softmax(合計1の重み分布に変換する関数)が Query と全 Key の内積を重みに変え、Value の加重和を返す
- **√dk の導出**(脚注4): 成分が平均0・分散1なら内積 q·k の分散は dk。したがって次元が大きいと内積が肥大し、softmax が飽和して勾配がほぼ消える。スケールなしの dot-product が大きい dk で additive に負けるのはこのため
- **masking**: 見せたくない位置の入力を −∞ にすれば softmax 後の重みが0になる — decoder の「未来を見ない」制約はこの1行で実装される

## Multi-Head — 8本の小さい attention は1本の大きい attention と同コスト

h=8 本に分けても計算量が増えない設計が肝で、無料で「複数種類の関係」を捉える能力を得ている。

- 機構: 学習行列 W_iQ, W_iK, W_iV で 512次元 → 64次元(dk=dv=d_model/h)に射影して8並列で attention、結果を連結して W^O で戻す
- ablation(部品を外して寄与を測る実験、Table 3): 1ヘッドは −0.9 BLEU(翻訳の自動評価スコア、高いほど良い)。ただし32ヘッドでも劣化 — 多いほど良いわけではない
- dk を16に縮めても劣化 — 内積という「相性関数」は次元を要する。決め方は簡単ではないという示唆
- 付録の可視化: 照応解決(its→Law)を担うヘッド、構文構造に沿うヘッドが教えていないのに自然発生

## 3用法 — 同じ機構が Q/K/V の出所を変えるだけで3役をこなす

| 用法 | Q | K/V | 役割 |
|------|---|-----|------|
| encoder self-attention | 前層 encoder | 同じ | 入力を双方向に文脈化 |
| decoder masked self-attention | 前層 decoder | 同じ | 未来を −∞ マスクし自己回帰を担保 — GPT 系の中身 |
| encoder-decoder attention | decoder | encoder 出力 | 生成中に入力を参照(翻訳の「見ながら書く」) |

## 学習レシピ — warmup と label smoothing は後代の原器になった

設定の多くがそのまま後続モデルに引き継がれた。

- データ: WMT14(機械翻訳の標準ベンチマーク)英独 450万文対を BPE(頻出文字列単位に分割する方式)共有語彙 3.7万で、英仏 3,600万文対を word-piece 3.2万で符号化
- 最適化: Adam(勾配の1次・2次統計を使う最適化手法、β₂=0.98)。学習率 = d_model^(−0.5) × min(step^(−0.5), step × 4000^(−1.5)) — 最初の4,000ステップ線形増、以後は逆平方根で減衰
- 正則化: dropout(学習時にランダムに無効化する正則化)0.1、label smoothing(正解の確率をわずかに割り引く)0.1 — perplexity(次トークン予測の自信のなさ)は悪化するが BLEU は向上する、という興味深いトレードオフ
- 推論: 直近チェックポイントの平均(base 5個 / big 20個)+ beam search(複数候補を並行維持する探索)幅4

## self-attention の勝因 — パス長 O(1) と並列性の両取り、代償は O(n²)

RNN に対する優位は「長距離依存の学びやすさ」と「並列性」の2軸で、代償が計算量である(Table 1)。

| 基準 | Self-Attention | RNN | 含意 |
|------|---------------|-----|------|
| 任意2トークン間のパス長 | O(1) | O(n) | 1ホップで繋がるため長距離依存が学びやすい |
| 逐次演算 | O(1) | O(n) | 全トークン同時計算 — LLM 時代への鍵 |
| 層あたり計算量 | O(n²·d) | O(n·d²) | 系列長 n < 次元 d なら有利。ただし長文脈で逆転 — 現代の弱点 |

## 結果 — 「安く強い」が並列化の証明

翻訳品質で当時の全モデルを超えながら、学習コストは 1/4 以下だった。

- WMT14 英独 28.4 BLEU — 既存の全モデル(アンサンブル含む)を 2.0 以上更新。英仏 41.8
- 学習コスト: 8×P100 GPU で 3.5日(base は12時間、≈3.3×10¹⁸ FLOPs)
- 汎化: 英語構文解析でも WSJ F1 92.7 — 翻訳専用機ではないことの初期証拠

## LLMへの系譜(要点のみ)

- decoder 側のみ→GPT 系(Claude / Llama)、encoder 側のみ→BERT 系([[BERT (2018)]])
- 並列性が[[スケーリング則]](リスト#4)の土俵を作り、O(n²) が長文脈研究を、付録の可視化が解釈可能性研究を生んだ
